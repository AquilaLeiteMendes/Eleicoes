## Notas históricas

- Município criado como **São Gonçalo** pela Lei estadual nº 1.931 (11/09/1928). Renomeado **Araripina** pelo Decreto-lei estadual nº 952 (31/12/1943).
- Até 1946 os prefeitos eram nomeados. A partir de 1947 passaram a ser eleitos por voto direto.
- Única intervenção estadual moderna: 2012 (governador Eduardo Campos).
- Reeleição permitida a partir da Emenda Constitucional nº 16/1997 (casos: Emanuel Bringel e Raimundo Pimentel).

## Como usar no GitHub

1. Crie um repositório (ex.: `araripina-prefeitos` ou adicione em um repositório existente de história local).
2. Faça upload deste arquivo como `lista-prefeitos-araripina.md` (ou `README.md` se for a página principal).
3. Opcional – GitHub Pages:
   - Vá em **Settings → Pages**.
   - Source: Deploy from a branch → `main` / `/ (root)`.
   - A página ficará disponível em `https://seu-usuario.github.io/nome-do-repo/`.

**Sugestão de melhoria não óbvia:** Adicione uma coluna de “Família política dominante” (Modesto, Ramos, Bringel, Arraes, Batista) e um gráfico de Gantt simples (Mermaid) mostrando a concentração de poder por clãs. Isso transforma a lista em ferramenta de análise genealógica-política do Sertão do Araripe.
